# Ionic Counter App

Aplicación Ionic con un contador interactivo que utiliza componentes `ion-button` e `ion-badge`.

## Características

✨ **Funcionalidades principales:**
- ➕ **Sumar**: Incrementa el contador en 1
- ➖ **Restar**: Decrementa el contador en 1
- 🔄 **Reiniciar**: Establece el contador en 0
- 📊 **Visualización**: Muestra el valor actual en un badge grande y colorido
- 🎨 **Interfaz intuitiva**: Botones grandes y fáciles de usar
- 💡 **Indicadores de estado**: Muestra si el contador es positivo, negativo o cero

## Tecnologías Utilizadas

- **Ionic Framework** - Framework para aplicaciones móviles híbridas
- **Angular** - Framework de desarrollo web
- **TypeScript** - Lenguaje de programación
- **SCSS** - Preprocesador CSS

## Instalación

1. Clonar el repositorio:
```bash
git clone https://github.com/josephisaiacunavasquez-sudo/ionic-counter-app.git
cd ionic-counter-app
```

2. Instalar dependencias:
```bash
npm install
```

3. Instalar Ionic CLI:
```bash
npm install -g @ionic/cli
```

## Uso

### Ejecutar en desarrollo
```bash
ionic serve
```

### Compilar para producción
```bash
ionic build --prod
```

## Funcionalidades

- **Sumar**: Botón verde que incrementa el contador
- **Restar**: Botón rojo que decrementa el contador
- **Reiniciar**: Botón amarillo que establece el contador en 0
- **Visualización**: Badge rojo que muestra el valor actual
- **Indicadores**: Texto que cambia según el estado del contador
